## 📝 Is README ko kaise save karein:

1. **Visual Studio** mein project ke **root folder** mein jaao
2. Right click → **Add** → **New Item**
3. **Text File** select karo aur naam do: `README.md`
4. Upar wala content copy karke paste karo
5. Save karo (Ctrl + S)

---
